MULTI-TENANCY
     PostgreSQL with row-level security. Tenant isolation is enforced by

OFFLINE-FIRST SYNC
     Flutter with idempotent sync keyed on client_uuid. Retries never
     create duplicates, so the app stays usable with no network at all.
